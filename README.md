# DATA301/DATA471 — Assignment 4

Quarto source for Assignment 4 (Alejandro C. Frery).

- **Exercise 1**: comparing ML and IQR-based estimators of the rate of an Exponential
  distribution, a bootstrap bias-corrected estimator, and a Monte Carlo comparison
  by mean squared error.
- **Exercise 2**: exploratory analysis of the `ausbeer` series (quarterly Australian
  beer production) from the `fpp2` package.

## Reproducing

```sh
quarto render assignment4.qmd
```

Requires R with the `fpp2` and `ggplot2` packages installed.
